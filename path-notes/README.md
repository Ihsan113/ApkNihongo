# NihonGo Patch Notes

Folder ini menyimpan catatan perubahan tiap versi agar root proyek tetap rapi.

Versi terbaru: [PATCH-NOTES-v0.1.10.md](PATCH-NOTES-v0.1.10.md).

- `PATCH-NOTES-v0.1.1.md` sampai `PATCH-NOTES-v0.1.9.md`: catatan perubahan versi.
- Catatan versi berikutnya tetap diletakkan di folder `path-notes/` dengan pola nama `PATCH-NOTES-vX.Y.Z.md`.

Source code, konfigurasi Gradle, dan workflow GitHub Actions tetap di lokasi proyek masing-masing; hanya dokumentasi perubahan yang dikelompokkan di sini.
